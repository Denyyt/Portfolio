# 🎨 Deny Yudha Taruna — Personal Portfolio Website
<!-- 1. OVERVIEW -->
Welcome to the repository of **Deny Yudha Taruna's** personal portfolio website! This project presents a modern, dark-themed showcase of creative works, skills, and case studies in **UI/UX Design** and **Game Design**.

<!-- 2. KEY FEATURES -->
## ✨ Key Features
* 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile displays.
* 🎯 **Dynamic Portfolio Filter**: Seamless project filtering by design category.
* ⌨️ **Typed.js Text Animation**: Smooth typing text effect for roles.
* 📜 **ScrollReveal Animations**: Entrance animations triggered on scroll.
* 🧭 **Smart Navigation**: Sticky header with auto-active link highlight.
* 📋 **Interactive Contact Card**: Quick-copy email action and direct WhatsApp integration.

<!-- 3. TECH STACK -->
## 🛠️ Tech Stack & Dependencies
* **Core**: HTML5, CSS3, JavaScript (ES6+)
* **Libraries**: [Boxicons](https://boxicons.com/), [Typed.js](https://mattboldt.com/demos/typed-js/), [ScrollReveal.js](https://scrollrevealjs.org/), [Poppins Font](https://fonts.google.com/specimen/Poppins)

<!-- 4. PROJECT STRUCTURE -->
## 📁 Project Structure
* `index.html` — Home & landing page structure
* `about.html`, `skills.html`, `portfolio.html`, `contact.html` — Subpages
* `style.css` — Global styling, layout variables & responsive queries
* `script.js` — Navigation logic, libraries setup & interactive utilities
* `img/` — Visual assets and project mockups

_Note: This portfolio website is still under development (ongoing development). The content, some image assets, project case studies, and detailed functionality testing will continue to be updated and optimized on a regular basis._
